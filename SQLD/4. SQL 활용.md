# SQL 활용

## 서브쿼리

- 메인 쿼리문 안에 다른 쿼리문
- IN(목록에 포함), ANY(하나라도 만족), ALL(모든 조건 만족), 
- EXISTS(존재 여부) 만 판단 SELECT 중요 x
- SELECT , FROM, WHERE 에서 쓸 수 있음

### 단일행 서브쿼리

- 서브쿼리가 하나의 값만 반환
- =, >, < 사용

### 다중열 서브쿼리

- 서브쿼리가 두 개 이상의 열을 반환

### 다중행 서브쿼리

- 서브쿼리가 여러 행을 반환
- (IN, ANY, ALL 사용)

### 스칼라 서브쿼리

- SELECT 문에서 서브쿼리가 하나의 컬럼

### 인라인 뷰

- FROM 절에서 임시 테이블처럼 활용
- 뷰는 실제 데이터 생성 x, 임시 목록
- 뷰 장점 : 보안성, 독립성, 편의성

### 상호연관 서브쿼리

- 외부 쿼리(메인)의 값을 참조해서, 행마다 반복 실행되는 서브쿼리
- 서브쿼리 안에서 메인쿼리 컬럼(A.컬럼)을 참조하면 상호연관 서브쿼리

## 그룹함수

- GROUP BY 절에서 여러 행을 하나의 결과 값으로 요약하는 함수
- 집계함수(COUNT, SUM, AVG, MIN, MAX) 외 ROLLUP, CUBE, GROUPING SET 존재

### ROULLUP

ROLLUP(col1, col2) -> (col1,col2) -> col1 -> 전체 행 순으로 그룹화

- 컬럼 순서 변경 시 결과 달라짐

### CUBE

CUBE(col1, col2) -> (col1,col2) -> col1 -> col2 -> 전체 행 순으로 그룹화

- 조합 가능한 전체 경우를 그룹화, 순서 상관 없음

### GROUPING SETS

- 그룹화할 대상을 지정 가능
- 지정에 따라 ROLLUP이나 CUBE와 같은 값

## 윈도우 함수

- GROUP BY랑 달리, 그룹화하지 않고 각 행에 대하여 계산된 값만 반환
- OVER 키워드와 함께 사용, OVER 안에서 집계함수 사용 불가
- ROWS: “행 개수 기준”, RANGE: “값 범위 기준”
- SELECT 단계에서 실행, SELECT, ORDER BY에서만 사용 가능

## 인덱스 효율
- 카디널리티가 높고(값이 다양하고), 선택도가 낮을수록(필터링 된 값이 작을수록) 인덱스 효율이 좋다.
- 주민번호 = 카디널리티 높고, 선택도 낮음

## Top N 쿼리

- 상위 N개 데이터 추출
    - TOP : SQL Server
    - LIMIT : MySQL, PostgreSQL
    - FETCH FIRST : DB2, Oracle
    - ROWNUM < N : Oracle

- LIMIT, FETCH, TOP 은 ORDER BY 다음 실행
- ORDER BY 필수
- 동일 순위 표시 WITH TIES
- ROWNUM 사용 시 =, > 연산자 사용 불가, < or <= 사용 가능

## DML (데이터 조작 언어)

### INSERT

- 넣고자 하는 값들을 순서대로 입력
    - INSERT INTO 학생 VALUES(5,'길동',23,1)
- 명시해서 추가, 명시되지 않은 컬럼은 NULL
    - INSERT INTO 학생 (학번, 이름, 학년) VALUES(5,'길동',23)

### UPDATE

- SET : 변경하고자 하는 값 지정
    - UPDATE 학생 SET 나이 = 20 WHERE 이름 = '선영'

### DELETE

- DDL TRUNCATE도 테이블의 데이터 삭제하나, ROLLBACK 불가

### MERGE

- MERGE INTO A USING B
    - B 테이블을 이용하여 A 테이블에 합병
- WHEN MATCHED THEN
    - ON 조건을 만족하면 수행

## DCL

### GRANT

- GRANT 권한 ON 테이블명 TO 유저명
- 권한 부여
- WITH GRANT OPTION 권한 부여 받은 사람이 권한 부여 가능

### REVOKE

- 권한 회수
- (ORACLE) WITH GRANT OPTION 부여 받은사람까지 자동회수
- (SQL Server) WITH GRANT OPTION 부여 받은사람 자동회수 x
