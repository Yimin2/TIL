## SQL

- RDMS 데이터 생성, 조회, 수정, 삭제를 위한 표준 언어

### DDL (정의어)

- 테이블 생성, 변경, 삭제
- CREATE, ALTER, DROP, RENAME, TRUNCATE
- TRUNCATE - 테이블은 삭제 되지 않고, 데이터만 삭제, Rollback x
- DROP CASCADE CONSTRAINT - 관계된 참조되는 제약조건까지 삭제

### DML (조작어)

- 데이터 조회, 삽입, 수정, 삭제
- SELECT, INSERT, UPDATE, DELDETE

### DCL (제어어)

- GRANT(권한 부여), REVOKE(권환 회수)

### TCL (트랜잭션 제어어)

- COMMIT, ROLLBACK, SAVEPOINT

- SUM -  같은 행 SUM + NULL = NULL

### NULL

#### NVL(컬럼, 대체값)

- 컬럼 값이 null이면 대체값, null이 아니면 원래 값

#### NULLIF(컬럼1, 컬럼2)

- 두 컬럼 값이 같으면 null, 다르면 첫번째 값

#### COALESCE(컬럼1, 컬럼2, 컬럼3...)

- 가장 먼저 null이 아닌 행의 값

### CASE 문 / DECODE 함수

#### CASE 문

- WHEN 조건 THEN 결과

#### DECODE 함수

- CASE 문과 결과 값 동일 (조건, 결과)

### LIKE 연산자

- 와일드카드
- % 0개 이상의 문자
- _ 1개의 문자

### NULL 비교 연산자

- IS NULL
- IS NOT NULL
- =NULL, !=NULL x

### 연산자 우선순위

- () -> * / -> % -> 비교연산자, IS NULL, LIKE, BETWEEN, IN -> NOT -> AND -> OR

### GROUP BY

- 그룹화하여 집계함수 결과를 산출
- WHERE로 먼저 필터링 후 수행하는 것이 성능상 유리

### HAVING 절

- 그룹화된 결과에 대한 조건
- WHERE은 행에 조건, HAVING 그룹에 조건
- 집계함수 가능

### ORDER BY 절

- SELECT 보다 나중에 수행, Alias 사용 가능, 집계함수 사용 가능

#### 정렬 순서 (오름차순 기준)

- 숫자형 : 작은 수 -> 큰수
- 문자형 : 사전 순
- 날짜형 : 과거 -> 미래
- NULL : oracle 최대값, SQL server 최소값

### Join

#### EQUI JOIN

- = 를 사용해서 같은 값인 경우 조인

#### NON EQUI JOIN

- 비교 연산자를 사용하는 조인

### INNER JOIN

- 동일한 값이 있는 행만 반환
- JOIN 단독 사용 시, INNER JOIN 의미
- NULL 값은 조회 대상 아님

#### USING 조건 절

- 컬럼명이 같은 컬럼들만 조인

#### ON 조건 절

- 컬럼명이 다르더라도 조인

### NATURAL JOIN

- 동일한 이름을 갖는 모든 컬럼을 EQUI JOIN
- ON, USING 조건절 없이 조인 가능

### CROSS JOIN

- 두 테이블의 모든 행을 조합해서 출력

### OUTER JOIN

- JOIN 조건에서 일치하지 않는 행 NULL로 처리하며 포함

#### LEFT OUTER JOIN

- 좌측 테이블이 기준으로 결과 생성, 우측 테이블에 가져오는 컬럼 없으면 NULL

#### RIGHT OUTHER JOIN

- 우측 테이블이 기준으로 결과 생성, 좌측 테이블에 가져오는 컬럼 없으면 NULL

#### FULL OUTER JOIN

- 좌,우측 모든 테이터를 활용해서 결과 생성
