# 데이터 모델링의 이해

## 모델링 `52회`

- 현실 세계의 정보를 약속된 표기법을 활용해서 데이터베이스의 구조로 표현
- 특징 : `단`순화, `추`상화, `명`확화
- 유의사항 : 유연성, 유일성, 일관성
- 관점 : 데이터 관점, 프로세스 관점, 데이터와 프로세스의 상관 관점(CRUD 분석 기반)
- 업무에서 사용되는 모든 데이터를 포함해야 한다.
- 상위 구조 파악이 쉬우나, 상세 구현이 보이지 않음

## 모델링 단계

- 개념적 모델링(추상적 개념, ERD) -> 논리적 모델링 (정규화) -> 물리적 모델링 (DB)
- -> 갈수록 낮은 수준의 추상화 레벨
- 필수 구성요소 엔티티, 속성, 관계

### ERD

- Barker표기법
    - `#` PK
- IE표기법
    - PK 분리된 공간 할당

#### ERD 작성순서 (`도배설명차선`)

1. 엔티티 도출
2. 배치
3. 관계 설정
4. 관계명 기술
5. 관계 차수 기술
6. 필수/선택사양 기술

## ANSI-SPARC 스키마(DB 설계도) 구조

- 스키마 3계층 
    - 외부스키마 (사용자 뷰)
    - 개념스키마 (전체적인 뷰, DB관리자) `52회`
    - 내부스키마 (물리적 저장)
- 독립성
    - 논리적 독립성
        - 개념 스키마 변경 시, 외부 스키마 영향 x 
    - 물리적 독립성
        - 내부 스키마 변경 시, 개념/외부 영향 x

## 엔티티

- 유일한 식별자, 인스턴스가 2개 이상, 2개 이상의 속성을 보유, 다른 엔티티와의 관계 필수

### 엔티티 분류

#### 유무형에 따른 분류 (`개사유`)

- `유`형 : 물리적 형태 존재 (학생, 책, 고객)
- `개`념 : 형태는 없지만 개념적으로 구분 (과목, 학과, 부서)
- `사`건 : 특정 시점이 발생한 사건 (수강, 주문, 예약)

#### 발생 시점에 따른 분류

- 기본 : 다른 엔티티 영향 x, 독립적으로 존재, 부모 엔티티 (학생, 과목, 고객, 직원) `52회`
- 중심 : 기본 엔티티와 행위 엔티티를 연결 (수강신청, 주문)
- 행위 : 두 개 이상의 엔티티를 상속받아 생성 (수강내역, 주문내역)
- 관계 : N:M 관계 해소하는 중간 엔티티, 주식별자 없어도 됨 `52회`

## 속성

- 분리되지 않는 최소의 데이터 단위(원자성)

### 속성 특징

- 엔티티 = 속성의 집합, 1개의 속성 = 1개의 속성 값, 주식별자에 함수적 종속 (A 속성에 의해 -> B가 결정됨)

### 속성 분류

- 특성에 따른 분류
    - 기본 속성 : 원래 가지고 있는 속성 (이름, 학번)
    - 설계 속성 : 필요로 인해 만들어진 속성 (주문번호, 일련번호)
    - 파생 속성 : 변형되어 만들어진 속성, 계산된 값 (합계, 평균)
- 분해 가능 여부에 따른 분류
    - 단일 속성 : 하나의 의미로 구성 (이름, 학번)
    - 복합 속성 : 여러 개의 하위 속성 (주소 -> 시/도, 도로명, 건물번호)
    - 다중값 속성 : 여러 값을 가질 수 있으며, 별도 테이블로 분리 관리 (전화번호, 이메일, 취미)
- 구성방식에 따른 분류
    - 기본키 PK
    - 외래키 PK

## 도메인

- 속성의 데이터 타입과 크기의 제한 사항 정의 (무결성 보장)

## 관계

### 관계의 구성 (`관차선`)

- `관`계명 : 관계의 이름, 동사로 표현
- `차`수 : 엔티티 간의 참여자의 수를 표현
- `선`택사양 : 엔티티가 관계에 항상 참여하는지 여부

## 교차 엔티티

- 관계형 DB M:N 관계 표현 불가, 중간테이블 필요(교차 엔티티)

## 식별자

- 인스턴스를 유일하게 구분할 수 있는 속성 또는 속성의 집합

### 대표성 여부에 따른 분류

- 주 식별자 PK : 대표성, 유일성, 최소성, 불변성, 존재성(NotNull)
- 보조 식별자 AK

### 스스로 생성 여부에 따른 분류

- 내부 식별자
- 외부 식별자 FK

### 속성의 수에 따른 분류

- 단일 식별자
- 복합 식별자 : 둘 이상 속성으로 구성된 식별자

### 대체 여부에 따른 분류

- 본질 식별자
- 인조 식별자 : 인위적으로 생성한 식별자 (수강신청 번호), 
   - null 값 허용 x
   - 의미 없는 번호

## 식별자 관계 `52회`

- 강한 연결 관계
- 부모에게 받은 식별자를 자식 엔티티의 주식별자로 이용
- Null 있으면 안됨
- 부모와 자식 같은 생명주기

## 비식별자 관계 `52회`

- 부모에게 받은 식별자를 자식 엔티티의 일반 속성으로 사용
- IE 표기법 점선, Barker 표기법 Bar(ㅣ) 여부로 파악

## Key
- 
- 슈퍼키 : 유일성 o, 최소성 x
- 후보키 : 유일성 o, 최소성 o
- 기본키 : 후보키 중 대표, 개체무결성 - null, 중복 x
- 대체키 : 기본키를 제외한 후보키
- 외래키 : 다른 테이블의 기본키, 참조무결성 - 참조 가능해야함 `52회`
- 고유키 : 중복 불가, NULL 허용
