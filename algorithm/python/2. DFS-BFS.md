# 2. DFS (Depth-First Search)

- 깊이 우선 탐색
- 스택 자료구조를 활용하여 구현 (재귀 함수 사용 가능)
- 한 경로를 끝까지 탐색한 후, 다른 경로로 이동
- 주로 경로 탐색, 사이클 검출 등에 사용

```python
def dfs_recursive(graph, v, visited):
    # 1. 현재 노드 방문 처리
    visited[v] = True
    print(v, end=' ') # 처리 로직

    # 2. 인접 노드 확인
    for nxt in graph[v]:
        # 3. 방문하지 않았다면 즉시 재귀 호출 (파고들기)
        if not visited[nxt]:
            dfs_recursive(graph, nxt, visited)
```

# 3. BFS (Breadth-First Search)

- 너비 우선 탐색
- 큐 자료구조를 활용하여 구현
- 인접한 노드를 먼저 탐색한 후, 그 다음 깊이로 이동
- 최단 경로 탐색 등에 사용

```python
from collections import deque

def bfs(graph, start):
    n = len(graph)                # graph가 인접리스트(0..n-1)라고 가정
    visited = [False] * n
    distance = [-1] * n           # 시작점으로부터의 거리, 미방문은 -1
    q = deque([start])
    visited[start] = True
    distance[start] = 0

    while q:
        v = q.popleft()
        # print(v, end=' ')       # 필요하면 출력
        for nxt in graph[v]:
            if not visited[nxt]:
                visited[nxt] = True
                distance[nxt] = distance[v] + 1
                q.append(nxt)

    return visited, distance
```

4. 2차원 리스트에서의 탐색
```python
# 전제: graph는 2차원 리스트, n = len(graph), m = len(graph[0])
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

def dfs_grid(x, y, graph, visited):
    n = len(graph)
    m = len(graph[0])
    # 범위 검사
    if not (0 <= x < n and 0 <= y < m):
        return
    if visited[x][y] or graph[x][y] == 1:  # 예: 1이 장애물/이미 방문 표시일 때
        return
    visited[x][y] = True
    # 4방향 반복
    for dir in range(4):
        nx = x + dx[dir]
        ny = y + dy[dir]
        dfs_grid(nx, ny, graph, visited)
```
