# 1. 그리디 (탐욕법)
- 미래를 생각하지 않고, 현재 상황에서 당장 최선의 선택만 하는 방식
- 최적의 해를 보장하지 않음
- 주로 최적화 문제에 사용

```python 
n = 1260 # 거슬러 줄 돈
count = 0

# 큰 단위부터 순서대로 확인
coin_types = [10, 500, 50, 100]
coin_types.sort(reverse=True)

for coin in coin_types:
    count += n // coin # 해당 동전으로 거슬러 줄 수 있는 개수
    n %= coin          # 남은 돈

print(count) # 6 (500원 2개, 100원 2개, 50원 1개, 10원 1개)
```

2. 이진 탐색
- 정렬되어 있는 리스트에서 탐색 범위를 절반씩 좁혀가며 데이터를 찾는 방식
- 데이터가 미리 정렬되어 있어야 함
- start, end, mid 변수를 활용

```python
def binary_search(array, target, start, end):
    while start <= end:
        mid = (start + end) // 2
        
        # 찾은 경우 중간점 인덱스 반환
        if array[mid] == target:
            return mid
        # 중간점의 값보다 찾고자 하는 값이 작은 경우 왼쪽 확인
        elif array[mid] > target:
            end = mid - 1
        # 중간점의 값보다 찾고자 하는 값이 큰 경우 오른쪽 확인
        else:
            start = mid + 1
    return None

# 활용 예시
data = [1, 3, 5, 7, 9, 11, 13, 15]
result = binary_search(data, 7, 0, len(data) - 1)
print(result) # 3 (인덱스 번호)
```
