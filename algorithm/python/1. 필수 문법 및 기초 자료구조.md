### for 문
- range(start, end, step)
```python
# 0부터 4까지 (총 5번)
for i in range(5):
print(i, end=" ") # 0 1 2 3 4

# 1부터 10까지 2씩 건너뛰기
```

- enumerate(iterable, start=0) : 인덱스와 원소를 함께 반환

```python
products = ["티셔츠", "슬랙스", "청바지"]

# 기본값: 0번부터 시작
for i, name in enumerate(products):
    print(f"{i}순위 상품: {name}")

# 시작 번호를 1로 바꾸고 싶을 때
for i, name in enumerate(products, start=1):
    print(f"제{i}위: {name}")
```

- zip(*iterables) : 여러 개의 iterable을 병렬로 묶어서 반환

```python
items = ["상의", "하의", "신발"]
counts = [10, 5, 8]
prices = [20000, 30000, 50000]

# 세 리스트를 한 줄씩 가져옴
for item, count, price in zip(items, counts, prices):
    total = count * price
    print(f"{item}의 총 매출: {total}원")

# zip을 사용해 딕셔너리로 바로 만들기
item_dict = dict(zip(items, prices))
# 결과: {'상의': 20000, '하의': 30000, '신발': 50000}
```

## 3. 핵심 자료구조 (Collections)

### deque

- bfs 구현에 필수

```python
from collections import deque

queue = deque([1, 2, 3])
queue.append(4)      # 오른쪽 삽입
queue.popleft()      # 왼쪽 추출 (O(1))
queue.appendleft(0)  # 왼쪽 삽입
queue.pop()          # 오른쪽 추출 
```

### Counter

- 빈도수 계산에 유용
- .keys(), .values(), .items() 사용 가능
- most_common(n) : 빈도수 상위 n개 반환
- +, -, &, |  (더하기, 빼기, 교집합, 합집합)

```python
from collections import Counter
counter = Counter(['a', 'b', 'c', 'a', 'b', 'b'])
print(counter['a'])  # 2
print(dict(counter)) # {'a': 2, 'b': 3, 'c': 1}
print(counter.most_common(1))  # [('b', 3)]

c1 = Counter(a=3, b=1)
c2 = Counter(a=1, b=2)

print(c1 + c2)
```

6. 필수 수학 라이브러리

- itertools (순열 - 순서가 다르면 다른 것, 조합 - 순서 상관 없이 구성이 같은 것)

```python
from itertools import permutations, combinations

data = ['A', 'B', 'C']

# 순열 (순서 고려)
p = list(permutations(data, 2)) 
# 결과 : [('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')]

# 조합 (순서 무시)
c = list(combinations(data, 2))
# 결과 : [('A', 'B'), ('A', 'C'), ('B', 'C')]

# 중복 순열
from itertools import product
product(data, repeat=2) 
# 결과 : [('A', 'A'), ('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'B'), ('B', 'C'), ('C', 'A'), ('C', 'B'), ('C', 'C')]

# 중복 조합
from itertools import combinations_with_replacement
combinations_with_replacement(data, 2)
# 결과 : [('A', 'A'), ('A', 'B'), ('A', 'C'), ('B', 'B'), ('B', 'C'), ('C', 'C')]
```
