## 3. 핵심 자료구조 (Collections)

### deque

- bfs 구현에 필수

```python
from collections import deque

queue = deque([1, 2, 3])
queue.append(4)      # 오른쪽 삽입
queue.popleft()      # 왼쪽 추출 (O(1))
queue.appendleft(0)  # 왼쪽 삽입
queue.pop()          # 오른쪽 추출 
```

### Counter

- 빈도수 계산에 유용
- .keys(), .values(), .items() 사용 가능
- most_common(n) : 빈도수 상위 n개 반환
- +, -, &, |  (더하기, 빼기, 교집합, 합집합)

```python
from collections import Counter
counter = Counter(['a', 'b', 'c', 'a', 'b', 'b'])
print(counter['a'])  # 2
print(dict(counter)) # {'a': 2, 'b': 3, 'c': 1}
print(counter.most_common(1))  # [('b', 3)]

c1 = Counter(a=3, b=1)
c2 = Counter(a=1, b=2)

print(c1 + c2)
```

defaultdict

- int, list, set, dict, str 등 기본값 설정

```python
from collections import defaultdict
graph = defaultdict(list)
graph['A'].append('B') # 'A' 키가 없어도 에러 없이 리스트 생성 후 추가
```

6. 필수 수학 라이브러리
- itertools (순열 - 순서가 다르면 다른 것, 조합 - 순서 상관 없이 구성이 같은 것)
```python
from itertools import permutations, combinations

data = ['A', 'B', 'C']

# 순열 (순서 고려)
p = list(permutations(data, 2)) 
# 결과 : [('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')]

# 조합 (순서 무시)
c = list(combinations(data, 2))
# 결과 : [('A', 'B'), ('A', 'C'), ('B', 'C')]

# 중복 순열
from itertools import product
product(data, repeat=2) 
# 결과 : [('A', 'A'), ('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'B'), ('B', 'C'), ('C', 'A'), ('C', 'B'), ('C', 'C')]

# 중복 조합
from itertools import combinations_with_replacement
combinations_with_replacement(data, 2)
# 결과 : [('A', 'A'), ('A', 'B'), ('A', 'C'), ('B', 'B'), ('B', 'C'), ('C', 'C')]
```
