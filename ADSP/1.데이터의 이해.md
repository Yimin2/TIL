# 데이터의 이해

## 데이터와 정보

### 데이터의 정의

- 데이터 : 객관적 사실, 가공되지 않은 상태
- 정보 : 데이터를 가공하여 의미를 부여한 상태

### DIKW 피라미드

- 데이터(Data) : 가공 전 사실 그 자체
- 정보(Information) : 데이터를 통해 패턴 인식
- 지식(Knowledge) : 패턴을 통해 의사결정 활용
- 지혜(Wisdom) : 지식을 바탕으로 창의적인 전략

### 데이터의 유형

#### 형태에 따른 분류

- 정형 데이터 : 구조화된 형태 (예: 데이터베이스)
- 반정형 데이터 : 데이터를 설명하는 메타데이터 포함 (예: XML, JSON)
- 비정형 데이터 : 구조화되지 않은 형태 (예: 텍스트, 이미지)

##### 표현 방식에 따른 분류

- 정량적 데이터 : 수치로 표현 가능한 데이터
- 정성적 데이터 : 자료의 특징을 나타내는 데이터

#### 분석 목적에 따른 분류

- 수치형 : 연속형(키, 온도) / 이산형(학생 수, 상품 개수) -> 회귀분석
- 범주형 : 명목형(성별, 혈액형) / 서열형(등급, 순위) -> 분류분석

#### 암묵지, 형식지간 상호작용 (공표연내)

- 암묵지 : 개인의 경험과 직관에 기반한 지식
- 형식지 : 문서화된 지식, 쉽게 전달 가능

1. 공통화 : 암묵지 지식을 다른 사람에게 알려줌
2. 표출화 : 형식지 지식을 메뉴얼이나 문서로 전환
3. 연결화 : 교재, 메뉴얼에 새로운 지식 추가
4. 내면화 : 만들어진 교재, 메뉴얼에서 다른 사람의 암묵지를 터득

### 정보의 축적, 전달

- 기계 가독성, 검색 가능성, 원격 조작성

## DB 정의와 특징

### DB 특징 (공통저변)

- 공용 데이터 : 여러 사용자가 공유
- 통합된 데이터 : 중복 최소화
- 저장된 데이터 : 저장매체에 저장
- 변화되는 데이터 : 새로운 데이터 추가, 수정, 삭제 가능, 무결성 유지

### DB 설계 절차

1. 요구조건 분석
2. 개념적 설계 : 개념적 스키마 생성
3. 논리적 설계 : 개념적 ERD를 활용한 논리적 모델링
4. 물리적 설계 : 저장 구조 설계

### DB 관리 시스템(DBMS)

1. DBMS : DB를 생성, 관리하는 소프트웨어
    - 관계형 DBMS : 테이블 기반 (예: MySQL, Oracle)
    - 비관계형 DBMS : 문서, 키-값 저장소 등 (예: MongoDB, Redis)
2. DB 스키마 : DB의 구조와 제약 조건 정의
    - 메타데이터 : 데이터를 설명하는 데이터
    - 데이터 사전 : DB의 구조, 제약 조건, 인덱스 정보 저장
    - 인스턴스 : 특정 시점의 DB에 저장된 실제 데이터
    - 인덱스 : 데이터 검색 속도 향상을 위한 자료 구조
3. SQL : 데이터베이스 질의 언어
    - DDL(Data Definition Language) : 스키마 정의 (예: CREATE, ALTER, DROP)
    - DML(Data Manipulation Language) : 데이터 조작 (예: SELECT, INSERT, UPDATE, DELETE)
    - DCL(Data Control Language) : 권한 관리 (예: GRANT, REVOKE)
    - TCL(Transaction Control Language) : 트랜잭션 제어 (예: COMMIT, ROLLBACK)

## DB 활용

### 기업 내부 활용 DB

- OLTP(On-Line Transaction Processing) : 다량의 단기 거래를 실시간 처리
- OLAP(On-Line Analytical Processing) : 다차원 데이터를 대화식으로 분석
- CRM(Customer Relationship Management) : 고객 관리 시스템
- SCM(Supply Chain Management) : 공급망 관리 시스템
- ERP(Enterprise Resource Planning) : 전사적 자원 관리 시스템
- RTE(Real-Time Enterprise) : 실시간 정보 처리 시스템
- BI(Business Intelligence) : 비즈니스 인텔리전스 시스템
- BA(Business Analytics) : 비즈니스 분석 시스템
- Blockchain : 네트워크에 참여한 모든 사용자가 정보를 분산, 저장
- KMS(Knowledge Management System) : 지식 관리 시스템

### DW (Data Warehouse)

- 대규모 데이터 저장소
- ETL (Extract, Transform, Load) 프로세스 통해 데이터 통합
- ODS (Operational Data Store) : 실시간 데이터 임시 통합 저장소

#### 특징

- 주제지향성 : 분석목적 설정이 중요
- 데이터 통합 : 일관화 된 형식으로 저장
- 시계열성 : 히스토리를 가진 데이터
- 비휘발성 : 읽기 전용 - 수시로 변하지 않음

### DataLake

- 비정형 데이터를 저장하며 하둡과 연계하여 처리

* 하둡 : 대용량 데이터 분산 저장 및 처리 시스템
    - HDFS(Hadoop Distributed File System) : 분산 파일 시스템
    - MapReduce : 분산 데이터 처리 모델

# 데이터 가치와 미래

## 빅데이터의 이해

### 출현 배경

- 클라우드 컴퓨팅, 분산 처리 기술 발전

### 데이터 단위

- KB, MB, GB, TB, PB, EB, ZB, YB // peta, exa, zetta, yotta

### 빅데이터의 3V 특성

- Volume(규모) : 대용량 데이터
- Velocity(속도) : 실시간 데이터 처리 속도
- Variety(다양성) : 다양한 형태의 데이터
- 그 외 : Veracity(정확성), Value(가치), Validity(유효성), Volatility(변동성)

### 빅데이터에 대한 비유

- 빅데이터 = 원유 : 가공 전 원재료
- 데이터 마이닝 = 정제 : 원유에서 유용한 정보 추출

### 빅데이터가 만들어내는 변화 (전후양상)

- 표본조사 -> 전수조사
- 사전처리 -> 사후처리
- 질 -> 양
- 인과관계 -> 상관관계

## 빅데이터의 가치와 영향

### 가치 산정이 어려운 이유

- 특정 데이터를 언제, 어디서, 누가 활용할지 알 수 없음
- 기존에 가치 없는 데이터도 새로운 분석기법으로 가치를 창조

## 비즈니스 모델

### 빅데이터 주요 분석 기법

- 회귀분석 : 변수 간 관계 분석
- 분류분석 : 데이터 그룹화
- 연관규칙 : 여러 요소 간 관계 발견
- 유전자 알고리즘 : 최적화 문제 해결
- 기계학습 : 패턴 인식 및 예측

## 위기 요인과 통제 방안

- 사생활 침해 : 제공자 동의 책임에서 사용자 책임으로 전환
- 책임 원칙 훼손 : 결과 기반 책임 원칙 고수
- 데이터의 오용 : 알고리즘 접근 허용 및 알고리즙 해석가능한 알고리즈미스트 필요

* 알고리즈미스트 : 부당하게 피해가 발생한 사람들을 구제하는 전문인력

### 데이터 3법

- 개인정보 보호법, 정보통신망법, 신용정보법
- 가명정보의 개념 도입

### 개인정보, 가명정보, 익명정보

- 개인정보 : 특정 개인을 식별할 수 있는 정보, 동의를 받아 활용 가능
- 가명정보 : 추가 정보 없이는 특정 개인을 식별할 수 없는 정보
- 익명정보 : 어떤 방법으로도 특정 개인을 식별할 수 없는 정보, 자유롭게 활용 가능

### 개인정보 비식별화

1. 가명처리 (이상길, 35세 -> 홍길동, 30대)
2. 총계처리 (나이 20~29세, 30~39세)
3. 데이터 삭제 (주민등록 번호 -> 90년대생, 남자)
4. 데이터 범주화 (키 175cm -> 키 170~180cm)
5. 데이터 마스킹 (전화번호 010-1234-5678 -> 010-****-****)

### 미래의 빅데이터 (인자기)

- 인력, 자원(데이터), 기술

## 가치 창조를 위한 데이터 사이언스와 전략 인사이트

- 빅데이터 분석과 전략 인사이트

### 전략 인사이트 확보 방향

- big에 초점을 맞추지 마라 : 분석 목적에 맞는 데이터 구성과 기법이 중요
- 전략적 인사이트 확보 : 단순 분석을 넘어 실행 가능성 고려
- 가치 기반 분석 수행 : 일차원적 분석을 넘어 가치를 창출하는 다범위 분석 요구

## 전략 인사이트 도출을 위한 필요 역량

### 데이터 사이언스

- 데이터와 관련된 모든 분야의 전문지식을 종합한 학문
- 정형/비정형 데이터를 막론하고 데이터를 분석 (총체적 접근법)

### 핵심 구성 요소 (A, I, B)

- 분석(Analytics) : 수학, 확률, 머신러닝, 분석학 등
- IT : 프로그래밍, 데이터 엔지니어링, 컴퓨팅 등
- 비즈니스 분석 : 커뮤니케이션, 스토리텔링, 시각화 등

### 데이터 사이언티스트의 역량

- Hard Skills : 통계학, 프로그래밍, 데이터 처리 기술
- Soft Skills : 문제 해결 능력, 비즈니스 이해, 커뮤니케이션 능력
- 가트너가 제시한 역량 : 데이터 관리, 분석 모델링, 비즈니스 분석, 소프트 스킬
  하드 스킬은 이과적, 소프트 스킬은 문과적인 느낌

### 빅데이터 그리고 데이터 사이언스의 미래 (Di, c, a)

- Digitalization -> Connection -> Agency
- Digitalization : 아날로그 데이터를 디지털로 전환
- Connection : 다양한 디지털 데이터 연결 및 통합
- Agency : 데이터 기반 의사결정 자동화 및 지능화
